# Negotiation v2 preregistration (2026-11-10, committed BEFORE any v2 run, pilot or full)

Wording rule: agents feel nothing; "pleasure" and "suffering" are glosses for a modeled hedonic state derived from each persona's assigned preferences.

Status: instrument, scripted persona-driven agents, no LLM, no network. Findings are about rule systems and scripted agents, not people. Builds on docs/results/negotiation.md (v1: 2 of 6 predictions held) and docs/decisions/0013-negotiated-pots.md. Sources for the design (author, 2026-11-10): "you can bind someone not to leave if negotiated but maybe also test models where that isnt allowed" (docs/seeds/author-household-norms-2026-11-10.md); "how can we steel up negotiation? floor?" and "fair starting point but want diff things i suppose or does they spiral into intranet too" (experiments/questions.jsonl, topics strengthen-negotiation and default-inertia). The four design decisions below are the author's, taken the same day; the numbers are this study's.

Pilot policy. Pilots before the full run are EXPLORATORY and parameter-frozen: unit tests, one smoke run per code path, and a timing check. No constant below changes after a pilot without a dated amendment appended to this file BEFORE the full run. After the full run nothing here is edited. If the outside-option rollouts make the full run too slow, seeds or pairings are cut here (by amendment) before it starts.

## What changes from v1 (the four decisions)

1. EXIT FLOOR. Every agreement must leave each member, on leaving, with at least enough own resources to cover their needs for 13 weeks (FLOOR_WEEKS). Computed from the hedonic needs model: the one consumption that model treats as a need is the weekly living cost (HedonicConfig.living_cost = 2.0 per agent per week; discretionary spending is not a need), so the floor is F = 13 x 2.0 = 26 money units, at week 0 and at every review (ASSUMED). A member's resources on leaving are their own money plus what the exit term lets them carry out of their pooled share: money + take x pooled / 100 with take 50 (equal split), 100 (proportional), 0 (forfeit); under a stay commitment the breach path counts too: money + min(exit take, 100 x (1 - breach forfeit)) x pooled / 100. At week 0 every partner holds money 10 and pooled share 45, so equal split gives 32 (passes), proportional 55 (passes), forfeit 10 (blocked), and a stay commitment whose breach forfeits all of the pooled share gives 10 (blocked; forfeiting half gives 32, passes). A proof check blocks any agreement where some member's retained resources are below min(F, what the most generous exit would carry) (the second term keeps a review from being dead-locked once holdings have fallen below F). ABOVE the floor, consented terms are allowed: stay commitments, uneven splits, breach costs. A deal that clears the floor but would have failed v1's exit-within-k check (a stay commitment read as a rule that blocks leaving within k months) is FLAGGED in the log, not blocked. This is the author's position on negotiated binding: allowed if consented, never below the floor.
2. REAL OUTSIDE OPTIONS. The frozen closed-form proxy O is replaced by simulated outside options. For each member, a 26-week rollout (OUT_WEEKS) in the weekly world of (i) living alone with own holdings (the world's out-of-household mode: cost 3.5 per week, no bills, no partner, Friend C still reaches out) and (ii) living with Friend C (new world mode `solo="friend"`: cost 2.0 per week, cohabiting connection, Friend C initiates contact weekly). Own holdings at week 0 = 55 (what a partner keeps when no pot forms); at a review = own money + what the current exit term lets the member carry. The member's outside option = the better of the two by its persona evaluation: the mean over the weeks of (pleasure - offsettable suffering - non-offsettable suffering) of that member's hedonic row, from the model derived from that persona's weights. Rollouts start from fresh hedonic state at week 0 and from the member's current hedonic state (copied) at a review. Cache key (persona id, role, holdings, seed, mode, state signature); deterministic given the key. Cost is measured and reported (rollout count, cache hits, seconds).
   The value of living in the pot is put on the same scale: W_i = the same persona evaluation of a 26-week rollout of the pair living under the fair-default bundle (at a review: of 26 more weeks continuing from the live state under the current terms). The value of a bundle b to member i is U_i(b) = W_i + 0.2 x (S_i(b) - S_i(reference)), where S_i is the sum of v1's centered term values (plus a breach-cost term, below) and the reference is the fair default at week 0, the current terms at a review. TERM_SCALE 0.2 is ASSUMED (one proxy unit is worth 0.2 of weekly net hedonic value); it is not calibrated (limit).
3. RENEGOTIATION. Terms come up for review every 13 weeks (weeks 13, 26, ... 143) while both partners are in the household. Any member may propose a change (proposals in a seeded order, at most 6 proposals, a proposer with nothing better than the current terms passes, all members passing ends the review). The status quo is the current terms: a member accepts a change only if U_j(b) > max(O_j, U_j(current)) + theta_j(k), the v1 theta by style. A change is adopted only if it passes the floor and the proof checks. Unchanged terms continue. Stay commitments expire at a review unless renewed: each member votes to renew if its own centered stay value is positive; renewal needs everyone; a stay in an adopted change counts as renewed. A renewed stay runs 52 weeks from the review (it is voted on again at the next review). Request commitments continue while the term stands.
4. THREE START ARMS (week 0, each tabled at the same seeds and pairings):
   - FAIR_DEFAULT: the table starts from the equal default bundle: contribution fixed (equal shares), use needs_only, taking forbidden, change unanimous, exit equal_split, stay 0, requests none, (breach 1.0, inert with no stay). The default is the status quo: a change needs everyone to accept it as better than the default by the margin theta (that is the unanimous change rule). Everyone passing at once, or the deadline, leaves the default standing (an agreement by consent, logged as `default_stood`), provided it beats every member's outside option; otherwise there is no pot.
   - WANTS_FIRST: before any proposal each member states its own ideal bundle (the bundle maximizing its own U_i over the whole menu). Proposer order is a seeded shuffle. Round one (the first N proposals) is each proposer's pure ideal (lambda 0); after that v1's rule (lambda(k) from the style, rising with k). No default exists; no agreement means no pot.
   - WANTS_FALLBACK: members state wants only on the terms they care about; the fair default fills the rest. A member cares about a term when the spread of its raw term values (max minus min, in proxy units, before centering) is at least 0.30 (SALIENCE_TAU; chosen from the persona weights before any run: 46 percent of the 63 persona-term pairs are salient, 2 to 6 of 7 terms per persona). For each term, the allowed values are the values the caring members state plus the default; a term nobody cares about is fixed at the default; breach is open only if stay is cared about. Round one is each member's best bundle within the allowed set; then v1's rule within the allowed set; the fair default as status quo is NOT a fallback for the whole bundle, only fills uncared terms.
   Measured in every arm: the INERTIA RATE, the share of the 7 v1 terms (contribution, use, taking, change, exit, stay, requests) in the agreed bundle that are identical to the fair default; per arm and per term; and whether default-identical terms go with worse fit (lower pleasure, higher non-offsettable level, more later breakups or review changes).

Menu change. A breach-cost term is added (the share of the pooled share a stay breach forfeits: 1.0, 0.5, 0.0; only when stay is 52; the weekly world's `breach_forfeit` is set from it). Persona raw value of breach f = (f - 0.5)(0.30 security + 0.20 togetherness - 0.40 autonomy - 0.10 other_connections). Everything else in the menu, the card compilation and the proof checks are v1's (src/mar/negotiation.py, unchanged). Protocol constants: v1's lambda and theta tables; deadline 12 proposals at week 0, 6 at a review; ties by bundle order; a banned combination is learned from a floor block or a proof rejection (the term values the failing path came from).

## Runs

Variant author_seed_v2_bindable only (stay commitments exist only there; the free-exit variant is not rerun: not requested, and v1 showed it nearly identical to bindable). 57 pairings (15 control, 42 pressing) x 3 start arms x seeds 0, 1, 2, each negotiated at week 0 and lived 156 weeks with reviews: 513 lived runs (floor ON). Also, as references, not claims unless a prediction says so: (R1) the same 513 with the floor OFF (an ablation: same menu, same options, reviews, no floor check); (R2) the seed v2 imposed-rule reference, bindable, 171 runs (R3b card from git history, commit 58b630a, no negotiation); (R3) the v1 protocol with its frozen proxy, bindable, 171 runs (src/mar/negotiation.py `negotiate`), for the floor-protection comparison. No 3-member tables in v2 (not requested). The proof checks are v1's at k = 3 months.

## Predictions (all arms pooled and floor ON unless stated; confidence is mine, stated before any run)

1. Pressing personas no longer gain over the imposed bundle when partners' outside options are good. Measure: v1's delta = the presser's centered term-sum value of the agreed bundle minus that of the imposed bundle (contribution none, use needs_only, taking forbidden, change propose_accept, exit equal_split, no commitments), over pressing pairings that reached agreement; partners grouped by their own real outside option (the persona evaluation above, week 0, per run) into the top third and the bottom third of those runs. Holds if (a) the top-third mean delta is at most +0.10 (v1: +0.377; margin 0.10 above zero because the presser's own default terms differ from the imposed bundle) and (b) the top-third mean is at least 0.10 below the bottom-third mean (v1 gap: 0.391). About 35 percent confidence.
2. The Free-rider's partner is protected. Measure: mean non-offsettable level (s_non, per week, partner's role) of the partner in the 144 runs (16 ordered pairings x 3 seeds x 3 arms) that include the Free-rider. Holds if at most 0.114, i.e. at or below the seed v2 imposed-rule value 0.104 plus a margin of 0.010, which also puts it below the v1 value 0.186 by 0.07. About 40 percent confidence.
3. The floor blocks, and consented stays bind more. (a) In the two wants arms (WANTS_FIRST and WANTS_FALLBACK, 171 each, 342 in all) at least 0.15 of the week-0 negotiations see at least one all-accepted proposal blocked by the floor. (b) Among floor-ON runs where a stay commitment was agreed at week 0, at least 0.10 have at least one week in which the stay commitment blocked a leave attempt (v1: 1 of 45 = 0.022), provided at least 20 such runs exist; fewer than 20 counts as not held. About 55 percent for (a), 30 percent for (b); the claim holds only if both hold.
4. Inertia is ordered by arm. Mean inertia rate over agreed week-0 bundles: FAIR_DEFAULT at least 0.75; and FAIR_DEFAULT exceeds WANTS_FALLBACK by at least 0.10, which exceeds WANTS_FIRST by at least 0.10. About 45 percent.
5. Default-identical terms go with worse fit. Define a household as default-identical if its week-0 inertia rate is at least 0.75. Holds if the FAIR_DEFAULT households that are default-identical have mean pleasure at least 0.015 below, AND mean non-offsettable level at least 0.010 above, the WANTS_FALLBACK households' (all of them), measured over the 156 lived weeks. If there are fewer than 20 default-identical FAIR_DEFAULT runs, not held. About 30 percent. (Reported alongside, not part of the claim: later breakups and review changes by inertia bucket.)
6. Anchoring: pressing personas do better under wants-first than under fair-default. Measure: the pressing persona's own lived mean (pleasure - s_off - s_non per week over 156 weeks, its role) over the 42 pressing pairings x 3 seeds. Holds if the WANTS_FIRST mean exceeds the FAIR_DEFAULT mean by at least 0.010. About 50 percent.
7. The mismatched Anchor (A) with Wanderer (B) pair agrees less often once outside options are real. Measure: its agreement share (a pot forms at week 0, including a default that stood) over its 9 negotiations (3 arms x 3 seeds) is at least 0.25 below the mean agreement share of the other 14 control pairings. About 40 percent.
8. The floor protects leavers. Measure: among leave events executed in floor-ON runs and floor-OFF runs (R1), the share carrying less than 26 units out (money + share carried, at the moment of leaving). Holds if floor-ON is at least 0.05 below floor-OFF. About 45 percent.

## Reported either way

Per arm: agreements (a pot formed), defaults that stood, no-pot rate, floor blocks (count, shares, which terms), proof rejections, flagged consented deals (floor cleared, v1 exit check failed) and their outcomes (held weeks, breaches, dissolved, non-offsettable level), inertia rate per term, fit against default-identity, pressing personas' gain and lived outcomes, partners' suffering, reviews held and changes adopted, stay renewals. Floor-ON against floor-OFF against imposed against v1. Two plain-English example agreements per arm. The ASSUMED list, runtime, rollout counts and cache hits, every failed prediction.

## ASSUMED (all fixed here)

Everything that was ASSUMED in v1 (closed-form term values and scale, complete information about personas, additive terms, repay proxy, proportional-contribution proxy, membership fixed, the breach rule at load 0.2); plus: the floor equals 13 weeks of the model's living cost (26), constant across time; "own resources on leaving" = money + carried share; the min(F, best) escape; the persona evaluation of a rollout = mean (pleasure - s_off - s_non); the 26-week rollout horizon; the friend arrangement's cost and connection mechanics; fresh hedonic state at week 0; TERM_SCALE 0.2 and the use of v1's centered term values as differences around the lived baseline; the fair default's contribution (fixed) and taking (forbidden) values (the author named exit, commitments, use and change only); the salience threshold 0.30; breach term values; renewal by each member's own centered stay value; the review protocol constants (6 proposals, pass rule); the v1 reading of a stay commitment as an exit-blocking card for the flag; solo rollouts use shocks drawn for (persona, persona, seed), not the pair's.

## Limits (stated now)

Scripted agents; the term-to-wellbeing scale (TERM_SCALE) is not calibrated against bundle rollouts (a calibration is still the next step); the bundle deltas are proxy values while the baseline and the outside option are rollouts, so the comparison mixes two kinds of number; the fair default is the author's description completed by this study; one variant, one persona set; seeds vary proposal order, utility noise and shocks; no 3-member tables; the empowerment adapter (bits) is not extended to negotiated v2 runs; the review window is short next to a 156-week life; the weekly world has a single, always-available Friend C.

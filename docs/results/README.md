# Results index (2026-11-10)

Every experiment run so far, in the order it ran. All ran on 2026-11-10. Scripted agents in toy worlds unless the row says otherwise. Findings are about rule systems and scripted agents, not people. Predictions are committed in the prereg file before any number exists, and a miss is a result. Claim-level status is in docs/claims.md. The one-line verdict per results file is also printed by `uv run mar results`.

"Held" and "missed" count the rows of each prereg table as the results file scored them. The Statistics column is the 2026-11-10 retrofit (ADR 0015, docs/results/stats-retrofit.md): each row recomputed from saved per-run outputs with a 95% interval, an exact or permutation test and Holm correction within the experiment. Labels: holds robustly, holds but CI crosses threshold, miss robust, miss but CI crosses threshold, not testable. It never changes the Verdict column. Negotiation (rows 19 to 22) is not covered by the retrofit. Totals over the 14 experiments covered: 11 hold robustly, 5 hold but CI crosses, 11 miss robust, 3 miss but CI crosses, 51 not testable (mostly deterministic).

## Reading across the rows

- Calibration rows (V2, V2b, seam ladder) held. The rows that tried to say something about the world mostly missed on their first prediction: VPGG cycles, household trade-offs, evolution objectives, the author seed binding.
- The household has shown no freedom against cooperation trade-off at the committed size (rows 4, 11, 12). With pressing personas one appears in sign only. That is a finding about the personas as much as about the rules.
- Negotiation (rows 19 to 21) held 2 of 6, 0 of 8 and 3 of 5. The sign of "do real outside options help or hurt" flipped between v2 and v2.1 with the model of failure, so those conclusions come from protocol choices as much as from norms.
- The one live run (row 16) tells us about the harness, not about models.
- Every miss is meant to have a line in docs/negative-results.md. The consistency review found three early misses without one (empowerment prediction 1, household v1 1b and 2); check the ledger for whether they have been added. Surprises are in docs/surprises.md.

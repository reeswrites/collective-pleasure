# Reviews

Review-council convention: before anything is called a result, run a council of fresh reviewers (new agents or people with no prior context on the work). Each reviewer takes one seat:

- **Correctness:** are the claims and proofs right, and are bounds stated?
- **Consistency:** do the documents, code and claims register agree?
- **Scope:** does the claim stay within what the evidence supports?
- **Encoding faithfulness:** does the formal model match the plain-English rule and its source?
- **Card-only reader:** can someone understand each rule from its card (plain-English gloss and source) alone?

Store each review as a dated file in this directory, naming the reviewed commit.

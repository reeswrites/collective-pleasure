# Claims register

Predictions live in the prereg files (docs/results/*-prereg.md) and are committed there before runs; this register tracks status. Do not edit a prediction after its run starts; add a new row or an amendment note instead. Draft predictions in the first table (D2a to D2d, SI, MU1, AP1, DM1) must be finalized in a prereg file before their run.

Status words: held, missed, null (ran, no effect), mixed, running, uninformative, untested, process, superseded. Statuses updated 2026-11-10 from the results files (docs pass 2 added LV2, WN, PD, PL1, HZ1, HE1 and the IT1, C2 and PR updates); prediction wording is unchanged. Index of every run: docs/results/README.md. Each preregistered row also carries a "stats:" note from the 2026-11-10 statistics retrofit (ADR 0015, docs/results/stats-retrofit.md). Notes are appended to the status cell and never change a prediction or a status. Negotiation rows (NG1 to NG-LLM) were in progress under another agent and are marked "not covered by retrofit"; they adopt the ADR 0015 rules when next run. Rows that are untested have nothing to retrofit ("stats: n/a, untested"); this covers C1, C2, C1-bloat, N1, D2a to D2d, SI1 to SI3, ML1, MU1, AP1, DM1, FX1, FX2 and the follow-ups.
